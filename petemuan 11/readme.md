# Aplikasi Pendaftaran Kegiatan Mahasiswa

## Deskripsi
Aplikasi Pendaftaran Kegiatan Mahasiswa merupakan program sederhana berbasis GUI (Graphical User Interface) yang dibuat menggunakan bahasa pemrograman Python dengan library Tkinter. Aplikasi ini digunakan untuk mengisi data mahasiswa yang ingin mengikuti kegiatan tertentu.

Program ini dibuat sebagai tugas praktikum untuk menerapkan penggunaan berbagai komponen GUI pada Python.

## Fitur Aplikasi
Aplikasi ini memiliki beberapa fitur, yaitu:

1. **Input Nama** – Mengisi nama mahasiswa menggunakan Entry.
2. **Program Studi** – Memilih program studi menggunakan Combobox.
3. **Jenis Kelamin** – Memilih jenis kelamin menggunakan Radiobutton.
4. **Pilihan Kegiatan** – Memilih kegiatan menggunakan Checkbutton dan Listbox.
5. **Alasan Mengikuti Kegiatan** – Mengisi alasan melalui Text.
6. **Tombol Daftar** – Menampilkan hasil pendaftaran dan pesan konfirmasi.
7. **Tombol Reset** – Menghapus seluruh data yang telah diisi.
8. **Menu File** – Menyediakan pilihan untuk keluar dari aplikasi.
9. **Menu Bantuan** – Menampilkan petunjuk penggunaan dan informasi aplikasi.
10. **Validasi Input** – Memastikan nama dan program studi sudah diisi sebelum data dikirim.
11. **Keyboard Event** – Tombol Enter dapat digunakan untuk menjalankan proses pendaftaran.

## Teknologi yang Digunakan
- Python
- Tkinter
- Messagebox
- Toplevel

## Cara Menjalankan Program

1. Pastikan Python sudah terinstal di komputer.
2. Simpan kode program dengan nama `main.py`.
3. Buka terminal atau CMD pada folder tempat file disimpan.
4. Jalankan perintah berikut:

```bash
python main.py
```

5. Setelah itu, jendela aplikasi Pendaftaran Kegiatan Mahasiswa akan muncul.

## Tujuan
Tujuan pembuatan aplikasi ini adalah untuk memahami penerapan komponen GUI pada Python, seperti Entry, Label, Button, Combobox, Radiobutton, Checkbutton, Listbox, Text, Menu, dan Frame.

## Penutup
Melalui aplikasi ini, pengguna dapat mempelajari cara membuat program GUI sederhana yang memiliki fitur input data, validasi, pengolahan pilihan, serta tampilan informasi menggunakan Python Tkinter.
